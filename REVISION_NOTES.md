# Catatan Revisi Website

## Tahapan revisi
1. Memperbarui judul browser, metadata, nama brand, tagline, hero beranda, dan footer agar berfokus pada hubungan Indonesia–Turki.
2. Mengganti visual beranda yang sebelumnya membahas jaringan penyebaran Islam dengan enam tonggak hubungan Indonesia–Turki.
3. Menggunakan lampiran rujukan untuk menjaga narasi sejarah dan materi tetap berfokus pada hubungan Aceh–Utsmaniyah, hubungan diplomatik sejak 1950, pendidikan, budaya, dan kerja sama keislaman.
4. Menambahkan lokalisasi isi tiga materi pembelajaran untuk Bahasa Indonesia, Inggris, Arab, dan Turki.
5. Memastikan label utama, dasbor, linimasa, evaluasi teka-teki silang, halaman sumber, footer, judul browser, serta metadata deskripsi mengikuti bahasa aktif.
6. Mempertahankan struktur komponen dan fitur progres yang sudah ada.

## Catatan penerjemahan
Nama diri, nama institusi, URL, dan judul bibliografi dipertahankan sesuai sumber agar rujukan dapat ditelusuri. Jika suatu istilah merupakan nama resmi program atau lembaga, nama aslinya dipertahankan.

## Verifikasi
Pemeriksaan sintaks dilakukan pada file TypeScript/TSX. Build produksi perlu dijalankan di lingkungan dengan dependensi proyek terpasang; pada lingkungan pemeriksaan ini, perintah build belum dapat dijalankan karena dependensi Vite tidak dapat dieksekusi.
